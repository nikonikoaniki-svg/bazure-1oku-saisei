# たてがき400 v2

Chromebook向けの20字×20列＝400字の縦書き原稿用紙アプリです。

## v2で強化した点
- 「、」「。」をマス右上に表示
- 「」『』（）【】などを縦書き向けに回転表示
- 算用数字 0〜9 を縦書き用に横倒し表示
- アルファベットも縦書き用に横倒し表示
- 長音符「ー」等を縦組み向けに表示
- 行頭禁止・行末禁止文字を増やし禁則処理を強化
- 開き括弧が列末に残りにくいよう調整
- Backspace対応
- 最大400字
- 自動保存

## 入力方式
文章は最初から
右上 → 下 → 左隣の列 → 下
という縦書き原稿用紙の順序で管理します。

横書き文章を後から縦書きに変換する方式ではありません。

## GitHub Pages
`index.html` をリポジトリ直下に置けば動作します。
