# バズれ、1億再生！スター誕生☆

春・夏・秋・冬の4曲をリリースし、年間累計1億回再生を目指すブラウザゲームです。

## 遊び方

1. アーティスト名、性別、音楽ジャンルを決めます。
2. AワードとBワードを1つずつ選び、新曲のタイトルを作ります。
3. トレンド、歌手との相性、ハプニングなどによって再生数が決まります。
4. 春・夏・秋・冬の4曲で、年間累計1億回再生を目指します。

- 演歌
- ロック

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. `index.html`、`README.md`、`images`フォルダをリポジトリの直下へアップロードします。
3. リポジトリの「Settings」を開きます。
4. 左側の「Pages」を開きます。
5. 「Build and deployment」のSourceを「Deploy from a branch」にします。
6. Branchを「main」、フォルダを「/(root)」にして「Save」を押します。
7. 公開処理が終わると、GitHub PagesのURLから遊べます。
